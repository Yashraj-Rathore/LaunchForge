# Demo Applications and Evidence

This directory contains runnable fictional integrations and generated evidence.

```text
demos/
  spring-demo/       # LF-0307 local evaluation + LF-0406 live update/outage evidence
  react-storefront/  # LF-0505 React SDK targeting, rollout, and live kill-switch demo
  demo-media/
  benchmark-report/
  reliability-report/
```

Use only fictional data. Benchmark and reliability reports must include real commands/results and
limitations.

Start the complete deterministic platform and both demo surfaces with:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File eng/demo.ps1 -Action Start
```

`demos/demo-media/` contains screenshots and browser video generated by the opt-in real-system
Playwright capture in `tests/e2e/specs/demo-media.spec.ts`. The capture uses the running Control API,
PostgreSQL, Config Edge, browser SDK, and React storefront; the in-process storefront harness remains
only a fast SDK contract test.
